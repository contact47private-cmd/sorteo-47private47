04 / Cómo se elige al ganador@

A partir de esa hora, el sorteo solo puede iniciarse introduciendo un código privado que no está incluido en GitHub ni en el HTML público. Al confirmar, una función segura de Vercel genera en ese instante una semilla criptográfica aleatoria de 256 bits y deriva de ella el ganador y los 2 suplentes. El resultado se intenta guardar en almacenamiento persistente con una operación write-once (SET NX): si ya existe un resultado oficial, el servidor devuelve siempre el primero y se niega a crear otro. Así, recargar la página, usar otro dispositivo o repetir la petición no cambia el resultado oficial. La semilla, fecha/hora y SHA-256 de la lista quedan publicados después del sorteo para poder reproducir la selección.
